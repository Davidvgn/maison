# maison

Les pages de la maison : la journée de chaque enfant (Jérémy, Liam, Nina), la tablette de la cuisine, les exercices de sport et les guides « comment faire ».

- Site : https://davidvgn.github.io/maison/
- Coches partagées entre les téléphones et la tablette grâce à Firebase : mise en place et sécurité dans [FIREBASE.md](FIREBASE.md).
- Réglages des enfants (tâches, jours, sport) : `children.js`. Liste des tâches et calendrier : `chores-core.js`.
- Code en JavaScript ancien (ES5) pour tourner sur n'importe quel navigateur, même vieux (tablette de la cuisine : Android).
- L'état de la maison (lave-vaisselle, sèche-linge, étendage) est dans `house.js`.
